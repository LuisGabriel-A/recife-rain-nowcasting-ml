# Inference and environment contract

Inference serves the six **already trained** A301 models selected by corrected
pre-2021 validation. Loading/prediction never fit models, tune thresholds or
consult the test for selection. The scientific authority remains
[validation/README.md](validation/README.md) and its frozen configuration JSON.

## Environment

Use **Python 3.14.6**, matching `.python-version`. Runtime packages, including
numerical dependencies, are pinned in `requirements.txt` to the tested
environment. Notebook tools have direct pins in `requirements-dev.txt`; that
file is not a full lock of notebook transitive dependencies. No additional
web framework or test runner is needed.

From the repository root on Windows:

```powershell
py -3.14 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
& .\.venv\Scripts\python.exe -m src.check_environment
& .\.venv\Scripts\python.exe -m pip check
```

Install Python 3.14.6 first: `py -3.14` selects an installed 3.14 interpreter;
the checker verifies the exact patch version. For notebooks, install
`requirements-dev.txt` and check with `--development`. On Linux/macOS use
`python3.14` and `.venv/bin/python`. The existing `.venv-1` environment can be
used directly. A separate clean runtime installation was also validated; see
[productionization checks](validation/productionization.md). Notebook transitive
dependencies remain outside the runtime lock.

`RainPredictor` checks runtime pins and recorded artifact library versions before
loading. Use only trusted joblibs generated by this project's training code:
pickle-based loading can execute code and cross-version loading is unsupported.
See the official [scikit-learn persistence documentation](https://scikit-learn.org/stable/model_persistence.html).
Metadata checks detect inconsistency; they do not authenticate a joblib.

## Prepared-feature API

```python
from src.models.predict import RainPredictor
predictor = RainPredictor()  # load once
result = predictor.predict(features)  # mapping or nonempty pandas DataFrame
```

Supply **exactly** these 20 fields; incoming order may differ:

| Group | Ordered fields |
|---|---|
| Current observations | precipitation_mm, temperature_c, humidity_pct, pressure_station_mb |
| UTC cycles | hour_sin, hour_cos, day_of_year_sin, day_of_year_cos |
| Rain history | precipitation_lag_1h, precipitation_lag_2h, precipitation_lag_3h, precipitation_lag_6h, precipitation_sum_3h, precipitation_sum_6h |
| Previous hour | temperature_c_lag_1h, humidity_pct_lag_1h, pressure_station_mb_lag_1h |
| Current minus previous | temperature_change_1h, humidity_change_1h, pressure_change_1h |

The single definition is `src/features/schema.py`. Values must be real, finite
numbers. Text, booleans, complex values, empty input, duplicate columns, missing
features and extra columns (including targets/future rainfall) raise `ValueError`.
Nothing is imputed or text-coerced. The caller remains responsible for the
causality/meaning of precomputed features; names alone cannot prove correctness.

Output: six rows per input, sorted by these first two fields:

| Field | Meaning |
|---|---|
| sample_position | Zero-based input row position, independent of index labels |
| horizon_hours | Predict at exactly t+h, not accumulated rainfall over h hours |
| model_name | Frozen model family |
| probability | Class-1 predict_proba score in [0,1] |
| decision_threshold | Frozen threshold for that horizon |
| alert | probability >= decision_threshold |

Thresholds remain **0.99 / 0.06 / 0.78 / 0.79 / 0.85 / 0.67**. `probability` is an
**uncalibrated model score**, not a calibrated rainfall likelihood. No calibration
was fitted. False positives/negatives remain possible; inactive alerts do not
establish safe conditions. Severe rainfall remains the project's >=10 mm/h
definition, not an official INMET threshold.

## Hourly-history API

```python
from src.features.build_features import build_current_features
features = build_current_features(observations)
result = predictor.predict(features)
```

Input: DataFrame or list of records with exactly `datetime_utc` and the four
current-observation columns. Require at least **seven consecutive observed
hours**, t-6h through t; prediction time is the last timestamp. Explicit timezones
(ISO `Z` recommended) are normalized to UTC. Timestamps must be unique, ordered
and aligned to whole UTC hours. Naive times, gaps, duplicates and missing/nonfinite
measurements are rejected without resampling or imputation. Manual history also
requires rainfall >=0, humidity 0..100 and pressure >0; training is not refiltered.

Preserved formulas: hour sin/cos uses `2*pi*UTC_hour/24`; annual cycles use
`2*pi*UTC_day_of_year/365.25`, including leap years. Rain lags are t-1/2/3/6h.
Rolling sums include t and require exactly 3/6 observed hours. Other lags use
t-1h; changes are current minus previous hour. Only the latest sample is returned.
Every supplied row must be complete, even for a longer history: prefer the latest
seven complete hours. No observation after prediction time is used.

Complete **synthetic** CLI demonstration:

```python
import json
from pathlib import Path
import pandas as pd
from src.features.build_features import build_current_features

history = pd.DataFrame({
    "datetime_utc": pd.date_range("2020-06-01T00:00:00Z", periods=7, freq="h"),
    "precipitation_mm": [0, 0, 0, 0.2, 0.6, 1.0, 2.0],
    "temperature_c": [25.0] * 7,
    "humidity_pct": [85.0] * 7,
    "pressure_station_mb": [1010.0] * 7,
})
features = build_current_features(history)
Path("features.tmp").write_text(json.dumps(features.iloc[0].to_dict()), encoding="utf-8")
```

```powershell
python -m src.models.predict features.tmp
python -m src.models.predict features.tmp --model-dir models
```

Input JSON may also be a list of 20-feature objects. Duplicate JSON fields and
nonstandard NaN/Infinity constants are rejected before prediction. CLI outputs JSON records;
invalid input exits with code 2. `--model-dir` is operator-controlled; no model
upload is accepted by the application.

## Validation and remaining limits

Run `python -m unittest discover -s tests -v`. Tests cover threshold equality,
ordered features, invalid inputs, causal formulas and temporal boundaries.
Read-only integration compares existing estimators and 40+ feature-parity samples
across the dataset. Integration explicitly skips if ignored data/artifacts are
absent. Training regression tests fit only synthetic temporary fixtures.

A fresh clone needs locally obtained/audited data and then
`python -m src.models.train_final_models` **only if artifacts need generating**.
Do not routinely rerun selection: 2021 is an already inspected historical holdout.
Data-download URLs/access dates, usage metadata, project licensing and contributor
attribution remain pending. Live ingestion and public deployment are future tasks.
