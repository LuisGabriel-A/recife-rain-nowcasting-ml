# Data

This directory contains the datasets used by the Recife Rain Nowcasting project.

## Planned source

- **Institution:** Instituto Nacional de Meteorologia (INMET)
- **Location:** Recife, Pernambuco, Brazil
- **Temporal resolution:** Hourly observations
- **Research period:** 2018–2024

The research document does not yet identify the exact INMET station code or the exact data-download URL. These fields should be completed when the original dataset is added.

## Directory convention

```text
data/
├── raw/        # Original files exactly as obtained from the source
├── processed/  # Cleaned/transformed data generated by the project
└── README.md
```

### `raw/`

Files in `raw/` must remain unchanged after download.

Do not manually edit the original source files. Any cleaning or transformation should be reproducible in code and saved under `processed/`.

### `processed/`

Contains datasets created from the raw observations after steps such as:

- column normalization;
- date/time parsing;
- duplicate checks;
- missing-record checks;
- temporal continuity validation;
- feature engineering;
- target generation.

## Important temporal rule

A missing observation must **not** automatically be interpreted as zero precipitation.

Before building future targets (+1h to +6h), the pipeline must verify that timestamps represent the expected hourly intervals.

## Data versioning policy

Raw and processed data files are ignored by Git by default.

This avoids accidentally committing large datasets or redistributing source data before its usage terms have been reviewed.

The directory structure itself is preserved with `.gitkeep` files.
